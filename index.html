Conociendo el modelo CMMI

¿Qué significan sus siglas?

CMMI viene del inglés Capability Maturity Model Integration. En español se conoce como Modelo Integrado de Madurez de Capacidades.

No es un lenguaje de programación ni un programa para escribir código. Es una referencia que ayuda a mejorar los procesos de una organización.

¿Por qué es importante?

  • Permite trabajar con más organización.
  • Ayuda a controlar requisitos y cambios.
  • Facilita encontrar errores y corregirlos.
  • Permite tomar decisiones usando datos.
  • Promueve la mejora continua.

Niveles de madurez

Los niveles muestran cómo una organización puede ir mejorando sus procesos, desde un trabajo poco organizado hasta una mejora continua.

0

Incompleto

Las actividades pueden no realizarse de forma constante.

1

Inicial

El trabajo es impredecible y depende mucho del esfuerzo de cada persona.

2

Gestionado

Los proyectos se planean, se revisan y se les hace seguimiento.

3

Definido

La organización utiliza formas de trabajo y estándares comunes.

4

Gestionado cuantitativamente

Se utilizan datos y medidas para controlar el desempeño.

5

Optimizado

Se buscan mejoras continuas y se previenen problemas repetidos.

Para recordar: nivel 1 = se reacciona; nivel 2 = se gestiona; nivel 3 = se trabaja con estándares; nivel 4 = se controla con datos; nivel 5 = se mejora continuamente.

Calidad y verificación del software

⌕

Aseguramiento de calidad (QA)

Se enfoca en revisar si se están usando procesos adecuados para producir un software de calidad.

✓

Control de calidad (QC)

Se enfoca en revisar el producto y encontrar errores mediante pruebas.

◎

Verificación y validación

La verificación comprueba los requisitos. La validación revisa si la solución sirve para la necesidad del usuario.

Ejemplo: sistema de préstamos de equipos

Una institución necesita una aplicación para registrar préstamos y devoluciones de computadores, consultar cuáles están disponibles y reportar equipos dañados.

¿Cómo ayuda CMMI?

  • Definir claramente los requisitos.
  • Planear las tareas y asignar responsables.
  • Diseñar y programar con control de cambios.
  • Probar los préstamos y las devoluciones.
  • Guardar los resultados y corregir errores.
●

Ventajas de CMMI

Más organización: ayuda a tener claras las tareas y responsabilidades.

Menos errores: permite revisar el trabajo durante el desarrollo.

Mejores decisiones: utiliza datos para saber qué se debe mejorar.

Trabajo constante: busca que las buenas prácticas se mantengan.

◆

Ideas importantes

CMMI no garantiza un software sin errores.

No es una metodología de programación ni una herramienta que se instala.

Se puede utilizar junto con Scrum y otros enfoques de desarrollo.

Lo importante es que las prácticas ayuden al equipo y no se conviertan en documentos sin uso.
